# Техническое Задание

## 1. Цель Работы

Для успешного прохождения дисциплины “Техническое зрение” необходимо в команде разработать приложение по выбранной тематике “Оценка камер”.

## 2. Требования К Технологиям

Набор технологий может быть любой.

## 3. Требования К Использованию Приложения

Приложением должно быть просто воспользоваться другим студентам ваших групп при финальном тестировании.

## 4. Критерии Оценки Приложения

Приложение оценивается:

- по планомерности работы, которую можно отследить по отчетам в LMS и истории действий в открытом репозитории;
- по качеству описания документации как самого приложения, так как выбранных способов, методов, методик оценки и моделирования;
- по адекватности решения поставленной в задании задачи.

## 5. Оценка Команды И Участников

По критериям выше определяется максимальная оценка для команды, внутри команды оценка зависит от вклада самого участника.

## 6. Обсуждение Вопросов

Вопросы, комментарии, уточнения обсуждаются с представителями команд на очных занятиях.
