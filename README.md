## 🎯 Назначение приложения

Приложение предназначено для предварительной оценки качества камеры устройства по фотографии, метаданным снимка и справочной информации о модели камеры или телефона.

В проекте предусмотрены два варианта работы:

- консольная версия;
- графический интерфейс.

# 1. Состав проекта

| Файл / модуль        | Назначение                                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.py`            | Консольный интерфейс, основное меню, запуск анализа, просмотр списка, поиск, оценка, статистика, категории и удаление записей                     |

| `requirements.txt`   | Список Python-зависимостей                                                                                                                        |

# 2. Системные требования и подготовка

* Установленный Python.
* Наличие зависимостей из файла `requirements.txt`.
* Для RAW-файлов желательно установленное библиотечное окружение с поддержкой `rawpy`.
* Для режима MS SQL Server — доступ к серверу и библиотека `pyodbc`.

> Если файл `config.json` отсутствует, приложение создаст его автоматически и по умолчанию будет использовать SQLite.

## 4.1. Анализ новой фотографии

1. Запустите пункт **«Анализировать новое фото»**.
2. Введите полный путь к файлу изображения.
3. Дождитесь завершения обработки.
4. Приложение рассчитает метрики качества и попробует определить камеру по метаданным.
5. Если модель устройства найдена, будет выполнен поиск DxOMark-оценки в локальной базе.
6. Если модель не найдена автоматически, можно выбрать её вручную из списка моделей базы.

### Что учитывается при анализе

* резкость;
* уровень шума;
* динамический диапазон;
* яркость;
* контраст;
* насыщенность;
* экспозиция;
* метаданные камеры:

  * производитель;
  * модель;
  * ISO;
  * выдержка;
  * диафрагма;
  * фокусное расстояние.

### Поддерживаемые форматы

* `.jpg`
* `.jpeg`
* `.png`
* `.bmp`
* `.tiff`
* `.dng`
* `.cr2`
* `.nef`
* `.arw`

# 5.2. Рекомендации по созданию фотографий для анализа

Для получения наиболее корректной оценки качества камеры рекомендуется выполнять анализ на основе набора из **пяти изображений**, снятых при одинаковых условиях освещения и расстоянии до объекта съёмки.

Пользователь должен подготовить следующие изображения:

## 1. Шаблон резкости (ISO 12233)

Используется для оценки детализации изображения, уровня резкости и способности камеры различать мелкие элементы.

Шаблон позволяет определить качество передачи границ объектов и степень сохранения деталей после обработки изображения.

---

## 2. Шаблон шахматной доски

Применяется для оценки общей резкости изображения и качества передачи контрастных переходов между объектами.

Позволяет анализировать способность камеры воспроизводить чёткие границы без размытия.

---

## 3. Шаблон шума (ISO 15739)

Используется для определения уровня цифрового шума, возникающего при работе сенсора камеры.

Оценка выполняется на основе международного стандарта **ISO 15739**, регламентирующего методы измерения шумов на изображениях.

---

## 4. Цветовая палитра

Позволяет оценить точность цветопередачи путём сравнения эталонных цветов и цветов, полученных камерой.

Используется для анализа отклонений цветовых значений и определения корректности воспроизведения оттенков.

---

## 5. Фотография произвольной сцены

Рекомендуется фотографировать объект с большим количеством деталей, текстур и переходов яркости.

Например:

- улицу;
- природный пейзаж;
- интерьер помещения;
- предметы с мелкими элементами;
- сложные по освещению объекты.

Данное изображение используется для общей оценки качества камеры и анализа поведения алгоритмов обработки изображения в реальных условиях съёмки.

---

### Рекомендации по съёмке

Для повышения точности анализа рекомендуется:

- использовать одинаковое расстояние до шаблонов;
- избегать движения камеры во время съёмки;
- выполнять съёмку при стабильном освещении;
- не использовать цифровое увеличение (zoom);
- сохранять исходное качество фотографии без дополнительного сжатия.

---

# 5.3. Инструкция по съёмке на iPhone Pro (Apple ProRAW)

Для корректного анализа фотографий, сделанных на устройствах серии **iPhone Pro**, рекомендуется использовать формат **Apple ProRAW**, позволяющий сохранять больше информации об изображении и метаданных камеры.

Использование ProRAW уменьшает влияние встроенной обработки изображения и позволяет получить более точные результаты анализа.

Поддержка доступна только для моделей серии:

- iPhone Pro;
- iPhone Pro Max;

начиная с устройств, поддерживающих формат Apple ProRAW.

# 6. Критерии оценки качества камеры

Общая оценка камеры формируется на основе нескольких технических критериев и результатов тестирования изображения.

Используются следующие показатели:

## 6.1. Разрешение изображения

Оценивается способность камеры сохранять мелкие детали изображения и воспроизводить объекты без существенной потери качества.

---

## 6.2. Резкость

Для оценки резкости используется международный стандарт **ISO 12233**, регламентирующий методы измерения резкости изображения и применение специализированных тестовых шаблонов.

Резкость позволяет определить способность камеры передавать границы объектов и мелкие детали без размытия.

---

## 6.3. Шум изображения

Оценка уровня шума выполняется согласно международному стандарту **ISO 15739**, определяющему методы измерения цифрового шума.

Данный показатель характеризует количество помех, возникающих на изображении, особенно при недостаточном освещении или высоких значениях ISO.

---

## 6.4. Яркость

Определяется уровень освещённости изображения и корректность передачи экспозиции.

Параметр позволяет оценить способность камеры сохранять детали как в светлых, так и в тёмных участках изображения.

---

## 6.5. Цветопередача

Для анализа используется сравнение полученных цветов с эталонными значениями в пространстве **LAB**.

Расчёт отклонений основан на международном стандарте **ISO 11664-6 (CIEDE2000)**, учитывающем особенности восприятия цвета человеком.

Данный критерий позволяет определить точность воспроизведения цветов камерой относительно реальных объектов.

---

## 6.6. Справочная оценка DxOMark

Для формирования более полной оценки используются данные платформы **DxOMark**, специализирующейся на тестировании камер мобильных устройств.

Оценка DxOMark включает анализ следующих характеристик:

- экспозиции;
- цветопередачи;
- автофокуса;
- детализации изображения;
- уровня шума;
- артефактов;
- качества зума;
- эффекта боке;
- качества видеосъёмки.

При определении модели устройства по **EXIF-метаданным** приложение автоматически сопоставляет её с локальной базой данных **DxOMark** и выводит итоговую справочную оценку камеры.

Использование DxOMark позволяет дополнительно сравнить результаты локального анализа изображения с независимой системой оценки качества камер.

---

На основе совокупности перечисленных критериев формируется итоговая комплексная оценка качества камеры устройства, используемая системой при анализе изображений.

---

# 7. Как интерпретировать результаты

Общая оценка формируется на основе набора технических признаков изображения.

В расчёт входят:

* резкость;
* шум;
* динамический диапазон;
* яркость;
* насыщенность;
* правильность экспозиции.

Для RAW-файлов используется отдельная логика обработки с учётом сырых байер-данных.

Если модель камеры найдена в базе DxOMark, приложение дополнительно показывает справочную оценку. Это помогает сопоставить результат анализа снимка с известной моделью устройства.

---

# 8. Форматы файлов и особенности обработки

* Обычные изображения обрабатываются через `Pillow` и `NumPy`.
* RAW-файлы `DNG`, `CR2`, `NEF` и `ARW` обрабатываются через `rawpy`, если библиотека установлена.
* Если `rawpy` отсутствует, RAW-файл будет обработан как обычное изображение.
* Метаданные EXIF используются для определения модели устройства и параметров съёмки.

# 10. Ограничения и рекомендации

* Для корректной работы лучше использовать фотографии, сделанные камерой или смартфоном с сохранёнными метаданными.
* Если модель не определяется автоматически, её можно выбрать вручную только из списка, который есть в локальной базе DxOMark.
* Качество оценки зависит от исходного изображения: слишком маленькие, сильно сжатые или повреждённые файлы могут дать менее точный результат.
* При подключении к MS SQL Server нужно проверить корректность:

  * сервера;
  * порта;
  * имени базы;
  * учётных данных.
