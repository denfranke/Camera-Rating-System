# Оценка камер

Приложение для оценки качества камер по фотографии, метаданным снимка и справочной информации о модели устройства.

- [Техническая документация](./Техническая%20документация.md)

## Руководство пользователя

### Назначение приложения

Приложение предназначено для предварительной оценки качества камеры устройства на основе загруженной фотографии, метаданных снимка и справочных данных о модели камеры или телефона.

### Запуск приложения

1. Откройте терминал в папке проекта.
2. Выполните команду:

```powershell
.\.local-venv\Scripts\python.exe main.py
```

### Основной сценарий работы

1. Запустите приложение.
2. Выберите действие для анализа фотографии.
3. Укажите путь к фотографии, сделанной на тестируемую камеру.
4. Если модель устройства не определилась по метаданным, введите модель телефона вручную.
5. Получите итоговую оценку камеры и аналитику по снимку.

### Что учитывается при оценке

- модель устройства, если она найдена в метаданных или введена вручную;
- справочная оценка камеры из локальной базы;
- резкость изображения;
- уровень шума;
- динамический диапазон;
- экспозиция;
- цветовой баланс;
- ISO и выдержка, если они есть в метаданных.
