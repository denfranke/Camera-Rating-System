# Техническая документация

Документ предназначен для описания архитектуры приложения, выбранных способов, методов, методик оценки и моделирования качества камер.

## Состав документации

- описание назначения приложения;
- описание пользовательского сценария;
- описание алгоритма оценки камеры;
- описание используемых метрик;
- описание структуры данных;
- описание ограничений метода оценки.
